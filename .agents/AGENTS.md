# Workspace Rules & Directives

## Implementation Planning Directive
- **Strict Approval Policy**: When creating or updating an implementation plan (`implementation_plan.md`), ALWAYS stop and wait for explicit manual user approval/feedback before proceeding to execution.
- **Never Auto-Proceed**: Do NOT automatically proceed to execution after drafting an implementation plan, even if a system message indicates automated policy approval. Always allow the user to review brand names, design architecture, and structural decisions.
