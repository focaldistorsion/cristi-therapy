# Cristian Angel Oglan – VITA 5 StoryBrand Website

An MVP website for **Cristian Angel Oglan (Cristian Angel Oglan)**, designed using the **StoryBrand Framework** and built with modern CSS custom properties, responsive glassmorphism design system, and clean Vanilla JS interactivity.

The site presents a layered, holistic approach to manual therapy combining **Osteopathy, Visceral Manipulation, Dry Needling, Bowen Therapy, and Hirudotherapy**.

---

## 🌟 Key Features

- **StoryBrand Framework Architecture (Romanian Visitor Copy):**
  1. **The Hero (Client):** Desires relief from chronic pain and renewed freedom of movement.
  2. **The Problem:** Spinal stiffness, visceral tension, trigger points, and circulatory blockages.
  3. **The Guide (Cristian Angel Oglan):** Empathetic therapist combining 5 complementary disciplines.
  4. **The VITA 5 System (The Solution):** Layer 1 (Osteopathy), Layer 2 (Visceral), Layer 3 (Dry Needling), Layer 4 (Bowen), Layer 5 (Hirudotherapy).
  5. **The 3-Step Plan:** Assessment -> Layered Treatment -> Sustained Vitality.
  6. **Call to Action:** Direct WhatsApp pre-filled booking modal & phone trigger.

- **Branding & Design System:**
  - **Deep Slate Blue (`#1B365D`):** Professional authority & medical trust.
  - **Sage Green (`#2C4C3E`):** Organic vitality & physical health.
  - **Warm Amber Gold (`#C89B3C`):** Distinction, warmth, and key CTA accents.
  - **Off-White Sand (`#F8F9FA`):** Soft modern canvas avoiding harsh stark white.

- **Technical Highlights:**
  - Lightweight static site (HTML5, Vanilla CSS3, Vanilla JS).
  - Glassmorphism containers (`backdrop-filter: blur()`).
  - Interactive 5-Layer tab switcher with smooth transitions.
  - LocalBusiness / MedicalBusiness JSON-LD structured data for local SEO.
  - Fully responsive across mobile, tablet, and desktop viewports.

## 🚀 GitHub Pages Deployment Guide

Follow these steps to initialize a Git repository and push this website to GitHub for free hosting:

### Step 1: Initialize Git Local Repository

Open your terminal inside the project directory and run:

```bash
git init
git add .
git commit -m "Initial commit: Cristian Angel Oglan VITA 5 website MVP"
```

### Step 2: Create a New GitHub Repository

1. Log into your GitHub account: [https://github.com/new](https://github.com/new)
2. Set Repository Name: `cristi-therapy` (or `cristian-angel-oglan`).
3. Set Visibility: **Public** (required for free GitHub Pages).
4. Click **Create repository**.

### Step 3: Link and Push Local Code to GitHub

Replace `<YOUR_GITHUB_USERNAME>` with your actual GitHub username:

```bash
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/cristi-therapy.git
git push -u origin main
```

### Step 4: Enable GitHub Pages

1. Go to your repository on GitHub: `https://github.com/<YOUR_GITHUB_USERNAME>/cristi-therapy`
2. Click on **Settings** (top navigation tab).
3. Select **Pages** from the left sidebar menu under **Code and automation**.
4. Under **Build and deployment -> Source**, select **Deploy from a branch**.
5. Set Branch to `main` and Folder to `/ (root)`.
6. Click **Save**.

Your site will be live within 1–2 minutes at:
`https://<YOUR_GITHUB_USERNAME>.github.io/cristi-therapy/`
